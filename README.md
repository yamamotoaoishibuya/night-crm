# Night CRM v1.6.2

## 今回の修正

### 来店履歴の保存が「保存中…」で止まる不具合を修正
保存処理を作り直しました。

- 保存成功 → 必ず「保存中…」解除
- 保存失敗 → 必ず「保存中…」解除
- 予期しないエラー → 必ず「保存中…」解除
- Supabaseの返答が15秒以上ない場合 → タイムアウトしてエラー表示
- 新規登録と履歴編集の保存処理を分離
- 編集時には created_by を書き換えない
- 保存成功後に履歴を再取得して画面を更新
- 閉じる操作でも busy 状態を解除

### 維持している機能
- 連れの名前
- 本指名 / 場内 / 指名なし
- 本指名 / 場内の場合の指名キャスト名
- 累計来店履歴の編集
- 年 / 月 / 日の選択式
- ボトル番号 / ボトル名
- 戻るスワイプ

## 更新手順
1. `night-crm-v1.6.2.zip` を展開
2. GitHubの `night-crm` を開く
3. 右上 `＋` → `Upload files`
4. `night-crm-v1.6.2` の中身を全部アップロード
5. Commit message：`Update to v1.6.2`
6. `Commit changes`
7. Vercel → `Deployments`
8. 最新が緑の `Ready` になるまで待つ
9. Night CRMを再読み込み
10. 来店履歴を1件テスト保存

## Supabase
今回は新しいDB列を追加していないためSQL実行は不要です。
v1.6.0のSQL実行済みなら、そのままでOKです。

## Vercel
環境変数の追加・変更は不要です。
