# Night CRM v1.5.1

## 今回の変更

### ホーム
- 集計表示は「表示中キャスト」だけ残しました
- 「全顧客」「来店履歴」「本指名 / 場内」の集計カードを削除
- ホームのキャスト欄を横スクロールから縦一覧へ変更
- 表示中のキャストを全員そのまま縦に確認できます

### 顧客新規登録
顧客フォルダ作成時に、1件目の来店履歴も同時登録します。

入力項目：
- 初回来店日
- 本指名 / 場内
- その日の使用金額
- その日の備考

顧客登録後は、この内容がそのまま累計来店履歴の1件目になります。

### 戻るスワイプ
「画面を進んだらSafari/iPhoneの左端スワイプで必ず1つ前へ戻れる」を標準仕様として修正。

対象：
- 管理者ホーム ↔ 全顧客
- 管理者ホーム ↔ キャスト
- 管理者ホーム ↔ 設定
- キャスト一覧 → 顧客一覧
- 顧客一覧 → 顧客概要
- 顧客概要 → 累計来店履歴

今後追加する画面も、この履歴方式を標準にします。

## 更新手順
1. `night-crm-v1.5.1.zip` を展開
2. GitHubの `night-crm` を開く
3. 右上 `＋` → `Upload files`
4. `night-crm-v1.5.1` フォルダの中身を全部アップロード
5. Commit message：`Update to v1.5.1`
6. `Commit changes`
7. Vercel → `Deployments`
8. 最新が緑の `Ready` になるまで待つ
9. Night CRMを再読み込み
   - Mac：Command + Shift + R
   - iPhone：Safariで再読み込み
