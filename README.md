# Night CRM v1.3.0

## 今回の追加
- キャストを「削除」せず非表示にできる
- 非表示にしても、そのキャストの顧客情報はすべて保持
- 非表示キャストはログイン不可
- 非表示にしたログインIDは、新しいキャスト登録で再利用可能
- 非表示キャスト専用の一覧画面を追加
- 非表示キャストを再表示可能
- 再表示時に、同じログインIDを別の表示中キャストが使用している場合は警告して停止
- 管理者画面右上の分かりにくい「パスワード変更」を削除
- キャスト本人の画面には「パスワード変更」を残す
- 管理者の全体検索では、非表示キャストの顧客情報も検索可能
- 検索結果の担当名には「（非表示）」と表示

## 重要：SupabaseでSQLを1回実行
`supabase/v1.3.0_login_id_reuse.sql` の内容をSupabase SQL Editorで実行してください。

これを実行しないと、非表示にしたログインIDを新しいキャストで再利用できません。

## 更新手順
1. ZIPを展開
2. GitHubの既存 `night-crm` リポジトリへ中身を上書きアップロード
3. SupabaseのSQL Editorで `supabase/v1.3.0_login_id_reuse.sql` を実行
4. Vercelの自動デプロイが `Ready` になるまで待つ
5. Night CRMを強制再読み込み

## 動作
- 表示中キャストの「非表示にする」
- 顧客情報は残る
- ログインIDは新規登録で再利用できる
- 上部の「非表示キャスト」から再表示
- 同じ番号が使用中なら警告が出て再表示されない
