# Night CRM v1.5.2

## 今回の修正

### 既存顧客の来店履歴
既に基本情報を登録済みの顧客でも、
「＋ 来店記録を追加」から過去の来店履歴を登録できます。

入力内容：
- 来店日
- 本指名 / 場内
- その日の使用金額
- その日の備考

過去の日付も登録可能です。
登録内容は最終来店日・最終本指名日・最終場内日・並び替え・累計来店履歴へ反映されます。

### 管理者設定
「アプリURLをコピー」を追加しました。

管理者 → 設定 → アプリURLをコピー

押すと現在のNight CRMのURLをコピーできます。

### 戻るスワイプ
固定ルールを維持しています。
画面を進んだ場合はSafari/iPhoneの左端スワイプで1つ前へ戻れます。

## 更新手順
1. `night-crm-v1.5.2.zip` を展開
2. GitHubの `night-crm` を開く
3. 右上 `＋` → `Upload files`
4. `night-crm-v1.5.2` フォルダの中身を全部アップロード
5. Commit message：`Update to v1.5.2`
6. `Commit changes`
7. Vercel → `Deployments`
8. 最新が緑の `Ready` になるまで待つ
9. Night CRMを再読み込み
