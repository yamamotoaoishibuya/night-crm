# Night CRM v1.4.2

## 修正内容
- v1.4.1 のビルドエラーを修正
- Safari/iPhoneの左端スワイプをブラウザ履歴と連動
  - 累計来店履歴 → 顧客詳細
  - 顧客詳細 → 顧客一覧
  - 顧客一覧 → キャスト一覧（管理者）
- 顧客一覧に最終来店時の種別を表示
  - 本指名
  - 場内
  - 通常
- 最終本指名日・最終場内日も顧客フォルダに表示
- 来店記録追加時に指名種別を選択
- 顧客一覧の並び順を切替可能
  - 登録順【デフォルト】
  - 最終来店日順
  - 最終本指名日順
  - 最終場内日順
- 累計来店履歴にも指名種別を表示

## 更新手順
1. ZIPを展開
2. GitHubの既存 `night-crm` を開く
3. 右上の `＋` → `Upload files`
4. `night-crm-v1.4.2` フォルダの中身を全部アップロード
5. Commit message：`Update to v1.4.2`
6. `Commit changes`
7. Vercel → `Deployments` → 最新が `Ready` になるまで待つ
8. Night CRMを再読み込み
