# Night CRM v1.2.1

## 今回の改善
- キャスト一覧をログインIDの数字が小さい順に並び替え
- ログインIDは文字列ではなく数値として比較
  - 例：3 → 8 → 82 → 172 → 398
- キャストカード左側に `No.82` のような番号表示を追加
- 管理者の全体検索でログインID検索に対応
  - 例：`82` と入力すると、そのキャストの顧客がヒット
- キャスト追加後も自動で数字順に並び替え
- 同じログインIDが発生した場合はキャスト名の五十音順で表示

## これまでの主な仕様
- キャスト本人のメールアドレス登録不要
- ログインIDは1〜3桁の数字
- 初期パスワードを自動発行
- 初回ログイン時にパスワード変更を強制
- 管理者は「初期設定待ち／変更済み」を確認可能
- 管理者からパスワード再発行可能
- キャストごとの顧客フォルダ
- 管理者の全体顧客検索

## 更新手順
1. ZIPを展開
2. GitHubの既存 `night-crm` リポジトリへ中身を上書きアップロード
3. Vercelの自動デプロイが `Ready` になるまで待つ
4. Night CRMを強制再読み込み

今回は環境変数やSupabase SQLの追加作業はありません。
