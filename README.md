# Night CRM v1.6.5

## 修正
「基本情報を編集」→「初回来店情報」の
本指名 / 場内などを変更して保存した時に
「保存中…」で固まる不具合を修正しました。

### 保存処理の変更
- 顧客基本情報保存：15秒タイムアウト
- 初回来店情報保存：15秒タイムアウト
- 新規顧客作成：15秒タイムアウト
- 保存成功 / 失敗 / 例外のどの場合でも必ず「保存中…」解除
- Supabaseのエラー内容を画面に表示
- モーダルを閉じた時も保存中状態を解除
- 初回来店の日付・本指名/場内・連れ情報を同じ保存処理で更新

## 更新手順
1. `night-crm-v1.6.5.zip` をダウンロード
2. ZIPを展開
3. GitHubの `night-crm` を開く
4. 右上 `＋` → `Upload files`
5. `night-crm-v1.6.5` の中身を全部アップロード
6. Commit message：`Update to v1.6.5`
7. `Commit changes`
8. Vercelを開く
9. Night CRMプロジェクト → `Deployments`
10. 最新が緑の `Ready` になるまで待つ
11. Night CRMを再読み込み
12. 既存顧客 → 基本情報を編集
13. 初回来店情報の「本指名 / 場内」を変更
14. 保存を押してテスト
15. 保存完了メッセージが表示されれば完了

## Supabase
SQL実行は不要です。

## Vercel
環境変数変更は不要です。
