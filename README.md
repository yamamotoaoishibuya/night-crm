# Night CRM v1.2.0

## 今回の追加
- キャスト本人のメールアドレス登録を廃止
- ログインIDを1〜3桁の数字に限定
- 内部では `ログインID@night-crm.invalid` を自動作成
- キャスト追加時に安全な初期パスワードを自動発行
- 初期パスワードは登録直後に1回だけ管理者へ表示
- 初回ログイン時にキャスト本人へパスワード変更を強制
- 管理者画面に「初期設定待ち／変更済み」を表示
- 管理者からパスワードをランダム再発行可能
- キャスト本人はログイン後も好きなパスワードへ変更可能

## 大切な仕様
変更後のパスワードそのものは、管理者にも表示されません。
管理者から確認できるのは「初期設定待ち／変更済み」の状態です。
忘れた場合は「パスワード再発行」で新しい仮パスワードを発行します。

## 必要なVercel環境変数
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

v1.1で `SUPABASE_SERVICE_ROLE_KEY` を設定済みなら、新しい環境変数の追加はありません。

## 更新手順
1. ZIPを展開
2. GitHubの既存 `night-crm` リポジトリへ中身を上書きアップロード
3. Vercelの自動デプロイが `Ready` になるまで待つ
4. 管理者でログイン
5. 「＋ キャスト追加」で、名前と1〜3桁のログインIDを登録
6. 表示された初期パスワードをキャストへ渡す
7. キャストは初回ログイン時に自分のパスワードへ変更

今回の試用版：v1.2.0
