# Night CRM v1.6.3

## 今回の変更

### ホームを「全データ横断検索」中心に変更
ホーム上部に大きな検索欄を配置しました。

もう「全顧客を探す」「キャストから探す」の2択から始める必要はありません。
保存されているデータを直接検索できます。

### 検索対象
- 顧客名
- LINE名
- 電話番号
- 職業・勤務先
- ランク
- 好きなお酒
- 基本メモ
- ボトル番号
- ボトル名
- 担当キャスト
- 担当キャストのログインID
- 来店日
- 来店時の本指名 / 場内
- 使用金額
- 来店履歴の備考
- 一緒に来た人の名前
- 連れの本指名 / 場内 / 指名なし
- 連れが指名しているキャスト名

### 検索結果
「何にヒットしたか」を表示します。

例：
顧客：長澤さん
担当：ゆか
ヒット：連れの名前「深澤さん」
来店日：2026/8/13
本指名：nana

検索結果をタップすると、その顧客フォルダを開きます。

### 維持
- 累計来店履歴の編集
- 連れの指名キャスト名
- 年 / 月 / 日の選択式
- ボトル番号 / ボトル名
- 戻るスワイプ

## 更新手順
1. `night-crm-v1.6.3.zip` を展開
2. GitHubの `night-crm` を開く
3. 右上 `＋` → `Upload files`
4. `night-crm-v1.6.3` の中身を全部アップロード
5. Commit message：`Update to v1.6.3`
6. `Commit changes`
7. Vercel → `Deployments`
8. 最新が緑の `Ready` になるまで待つ
9. Night CRMを再読み込み
10. ホーム検索で「連れの名前」を1件テスト
