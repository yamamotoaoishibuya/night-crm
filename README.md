# Night CRM v1.5.0

## 全体UIアップデート
今までの機能は残したまま、操作の流れを整理しました。

### 管理者トップ
下部固定ナビ：
- ホーム
- 全顧客
- キャスト
- 設定

### ホーム
- 全顧客検索への大きなショートカット
- キャスト一覧への大きなショートカット
- 表示中キャスト数 / 顧客数 / 来店履歴数 / 本指名・場内数
- よく使うキャストをすぐ開ける

### 全顧客
- 検索専用画面に整理
- 顧客名 / LINE / 電話 / メモ / 担当 / ID / 来店日を検索
- 顧客名以外でヒットした場合は担当キャストを表示
- 登録順 / 最終来店日 / 最終本指名日 / 最終場内日で並び替え

### キャスト
- カードは No. / 名前 / 顧客数 / 利用状態だけに整理
- パスワード再発行・非表示は「•••」管理メニューへ移動
- 誤操作しにくいUIに変更

### 顧客
- 顧客フォルダ一覧をシンプル化
- 最終来店の本指名・場内をバッジ表示
- 基本情報の編集画面から旧「最終来店日」「利用金額」を削除
  - 来店情報は「来店記録」へ一本化

### 設定
- 非表示キャスト
- ログイン情報
- アプリバージョン
- ログアウト

### そのまま維持
- Safari/iPhoneの戻るスワイプ
- 顧客フォルダ
- 最終来店日 / 最終使用金額 / 最終備考
- 来店記録
- 累計来店履歴
- 本指名 / 場内 / 通常
- キャスト非表示 / 再表示
- 非表示IDの再利用と重複警告
- 管理者メールログイン / キャスト数字IDログイン

## 更新手順
1. `night-crm-v1.5.0.zip` を展開
2. GitHubの `night-crm` を開く
3. 右上 `＋` → `Upload files`
4. `night-crm-v1.5.0` フォルダの中身を全部アップロード
5. Commit message：`Update to v1.5.0`
6. `Commit changes`
7. Vercel → `Deployments`
8. 最新のDeploymentが緑の `Ready` になるまで待つ
9. Night CRMを再読み込み
   - Mac：Command + Shift + R
   - iPhone：Safariで再読み込み
