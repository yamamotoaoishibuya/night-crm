# Night CRM v1.6.4

## 今回の追加

### 連れと登録済み顧客の紐付け
連れの名前を入力すると、登録済み顧客を部分一致で候補表示します。

候補に表示：
- 顧客名
- 担当キャスト
- LINE名
- 基本メモ / 備考
- ボトル番号
- ボトル名

候補をタップすると、その登録済み顧客と紐付きます。
該当者がいなければ、候補を選ばず未登録の連れとして名前のまま保存できます。

本指名 / 場内の場合、登録済み顧客を選ぶと担当キャスト名を指名キャスト欄へ自動反映します。

### 新規顧客の初回来店
顧客追加時の初回来店情報でも、通常の来店履歴と同じ連れ入力ができます。

### 既存顧客の初回来店修正
基本情報編集から最初の来店履歴を修正する場合も、連れ情報を編集できます。

### 維持
- 全データ横断検索
- 連れの名前検索
- 累計来店履歴編集
- 年 / 月 / 日の選択式
- ボトル情報
- Safari/iPhone左端スワイプで戻る

## 更新手順
1. `night-crm-v1.6.4.zip` をダウンロード
2. ZIPを展開
3. GitHubの `night-crm` を開く
4. 右上 `＋` → `Upload files`
5. `night-crm-v1.6.4` の中身を全部アップロード
6. Commit message：`Update to v1.6.4`
7. `Commit changes`
8. Vercelを開く
9. Night CRMプロジェクト → `Deployments`
10. 最新が緑の `Ready` になるまで待つ
11. Night CRMを再読み込み
12. 新規顧客の初回来店で「連れを追加」をテスト
13. 既存顧客と似た名前を入力して候補が出ることを確認

## Supabase
SQL実行は不要です。
既存の `companions` JSON内に紐付け情報を保存します。
